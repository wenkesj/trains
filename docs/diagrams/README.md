# Diagrams

Edit `overview.mmd` using [Mermaid](https://mermaid.js.org/), then run
`task docs:diagram` from the repository root to regenerate
`docs/public/images/overview.png` with Mermaid CLI 11.12.0.

The Overview and root README share this PNG. Commit the source and rendered image
together. Extra Mermaid CLI options can be passed after `--`.
