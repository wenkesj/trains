# Code reference

Signatures, types, docstrings, and source for Trains's Python API.

Start with `trains.datasets` to build reusable HF datasets. Use `trains.formats`
to select and validate source records, `trains.tracing` for native provider exports,
and `trains.datum.adapters` to render provider-native training datums.

[User guides](https://wenkesj.github.io/trains/#/docs/guides/overview)
